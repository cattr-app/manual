# Введение :id=intro :priority=10

Cattr — это приложение с открытым исходным кодом, созданное для управления проектами и отслеживания рабочего времени. Благодаря интеграциям с популярными таск-трекерами (такими как Redmine и Gitlab) и встроенному функционалу отслеживания активности, это отличный инструмент для увеличения продуктивности как в офисе, так и при удалённой работе. Cattr устанавливается на ваш  сервер, что обеспечивает конфиденциальность хранения данных.

?> Cattr состоит из двух частей. Одна размещается на вашем сервере и обеспечивает доступ к сохраняемым данным посредством API, а также web-интерфейс для управления Cattr и генерации отчетов. Вторая часть - это приложение для операционных систем Windows, Mac OS, Linux или мобильное приложение для OS Android, iOS. При помощи него пользователи выбирают задачи и  отслеживают отработанное время.


## Если вы — пользователь
Для начала работы, вам потребуются данные для доступа к учётной записи — адрес сервера, адрес электронной почты и пароль. Эти данные вы можете получить у системного администратора или руководства вашей компании. После получения учётных данных, загрузите приложение для вашей платформы на странице загрузки — [https://cattr.app/desktop](https://cattr.app/desktop)

?> Если у вас Windows, при запуске приложения Вы увидите предупреждение Microsoft SmartScreen. Это происходит из-за того, что приложение пока недостаточно популярно. Для продолжения установки нажмите сначала на “Подробнее”, а затем на кнопку “Выполнить в любом случае”. Если вы чувствуете себя небезопасно, Вы можете создать ПК-приложение из исходного кода самостоятельно: https://cattr.app/desktop-application   

При первом запуске приложение попросит вас ввести адрес сервера и данные вашей учетной записи - адрес электронной почты и пароль. После успешного входа в систему вы попадете на страницу со списком ваших задач. Для начала отслеживания рабочего времени нажмите на кнопку справа от названия задачи. В нижней части приложения вы увидите, какая задача сейчас активна, и общее количество отработанного времени за сегодня. Для остановки отслеживания времени нажмите на кнопку с таймером ещё раз.

?> Обратите внимание, что приложение для macOS запросит у вас разрешение на доступ к возможностям универсального доступа (для отслеживания активности клавиатуры и мыши) 
и записи экрана (для создания скриншотов). 

Для того, чтобы воспользоваться остальным функционалом Cattr, перейдите в веб-форму приложения: откройте браузер и введите адрес сервера, который вам предоставил администратор вашей компании. Для входа введите те же адрес электронной почты и пароль, которые вы использовали для входа в приложение на компьютере. Для настройки интеграций с системами управления проектов обратитесь за инструкциями к администратору вашей компании.

## Если вы менеджер или руководитель компании
Cattr позволит вам организовать эффективную работу полностью прозрачно и эффективно. Cattr имеет несколько инструментов, каждый из которых помогает решить определенный круг задач.

### Скриншоты и отслеживание активности
Для каждого пользователя вы можете отдельно активировать запись скриншотов и отслеживание активности клавиатуры и мыши.
Эти инструменты помогут точнее учитывать рабочее время, идентифицируя каждую задачу, и анализировать рабочую активность сотрудников.

### Дашборд
Дашборд позволяет увидеть то, над чем работают ваши сотрудники — как в реальном времени, так и в ретроспективе.

### Отчет по проектам
Данный отчёт показывает отработанное время в отдельных проектах  за выбранный промежуток времени.

### Отчет по использованию времени
Данный отчёт показывает отработанное время конкретных сотрудников на выбранных проектах и задачах.

### Отчет по запланированному времени
Данный отчёт рассчитывается один раз в сутки на 00:00:00 выбранной даты в часовой зоне, установленной для компании. Он показывает запланированное и отработанное время конкретных сотрудников на выбранных проектах и задачах, а также продуктивность выполнения задачи, рассчитанную как отношение отработанного времени к запланированному. Задачи в отчете отсортированы по проектам и внутри них - по фактическому времени работы над задачами по убыванию). Один клик мыши (в десктопной версии) или тап (в мобильной версии) по задаче раскроет список исполнителей с указанием фактически отработанного над задачей времени). Продуктивность указана только для задачи и не отображается в списке ее исполнителей.

!> Задачи в отчете могут иметь красный тег “Просрочено” (если дата выполнения задачи больше, чем было запланировано) и оранжевый тег “Сверхурочно” (если время выполнения задачи больше, чем было запланировано). 


### Универсальный отчет
Этот тип отчета позволяет настроить конкретные поля и столбцы для быстрого доступа к нужным данным. Он может быть создан как для компании (в этом случае его могут сформировать все пользователи с соответствующим доступом), так и для конкретного пользователя. 

Данные могут быть отсортированы по: 
* проектам -  в отчете отображается общее время работы всех пользователей и время работы каждого пользователя по отдельности на выбранных проектах, задачи “вкладываются” в проект и раскрываются при клике на него;

* пользователям -  в отчете отображается общее время пользователя на выбранных проектах, проекты “вкладываются” в пользователя и раскрываются при клике на него;

 * задачам -  в отчете отображается общее время работы всех пользователей и время работы каждого пользователя по отдельности на выбранных задачах, пользователи “вкладываются” в задачи и раскрываются при клике на него.
 
Также этот тип отчета включает в себя графики, они отображаются на фронтенде при формировании отчета, а также при скачивании отчета в формате Excel.
