# Введение :id=intro :priority=10

Cattr — это приложение с открытым исходным кодом, созданное для отслеживания рабочего времени. 
Благодаря интеграциям с популярными таск-трекерами (такими как Jira, Redmine, Gitlab и Trello) и встроенному функционалу отслеживания активности,
это отличный инструмент для увеличения продуктивности вашей команды как в офисе, так и при удалённой работе.

## Если вы — пользователь
Для начала работы, вам потребуются данные для доступа к учётной записи — адрес сервера, адрес электронной почты и пароль. Эти данные вы можете получить
у администрации или руководства вашей компании. После получения учётных данных, загрузите приложение для вашей платформы на странице загрузки — [https://cattr.app/desktop](https://cattr.app/desktop)

?> Ввиду того, что приложение для Windows ещё недостаточно популярно, при попытке запустить его, вы вероятно увидите предупреждение Microsoft SmartScreen.
В таком случае, нажмите сначала на ссылку "Подробнее", а затем на кнопку "Выполнить в любом случае".

При первом запуске, приложение попросит вас ввести сперва адрес сервера, а затем адрес электронной почты и пароль учётной записи. 
После успешного входа в систему, вы попадёте на страницу со списком ваших задач. Для начала отслеживания рабочего времени, нажмите на кнопку справа от названия задачи.
В нижней части приложения, вы увидите какая задача сейчас активна и количество отработанного времени. Для остановки отслеживания рабочего времени, нажмите на кнопку с
таймером ещё раз.

?> Обратите внимание, что приложение для macOS запросит у вас разрешение на доступ к возможностям универсального доступа (для отслеживания активности клавиатуры и мыши) 
и записи экрана (для создания скриншотов). 

Для доступа к веб-приложению, откройте браузер и перейдите по ссылке с адресом сервера, которую вам предоставил администратор вашей компании. 
На странице входа необходимо ввести тот же адрес электронной почты и пароль, которые вы использовали для входа в приложение на компьютере.
Для настройки интеграций с таск-трекерами, обратитесь за инструкциями к администратору вашей компании.

## Если вы руководите компанией
Cattr позволит вам лучше узнать то, как работают ваши сотрудники. Внутри у Cattr есть несколько инструментов, каждый из которых помогает решить
определённый круг задач.

### Скриншоты и отслеживание активности
Для каждого пользователя вы можете отдельно активировать запись скриншотов и отслеживание активности клавиатуры и мыши.
Эти инструменты помогут более точно подсчитывать количество рабочего времени и иметь представление о том, насколько 
ваши сотрудники сфокусированы на работе.

### Дашборд
Дашборд позволяет увидеть то, над чем работают ваши сотрудники — как в реальном времени, так и в ретроспективе.

### Проектный отчёт
Проектный отчёт даёт представление о количестве рабочего времени, затраченного на отдельные проекты и задачи за выбранный
промежуток времени.

### Временной отчёт
Временной отчёт позволяет оценить временные затраты конкретных сотрудников на выбранных проектах и задачах.

## Установка
Обратите внимание на то, что Cattr — это on-premises приложение, которое требует установки на сервер в рамках вашей инфраструктуры.
Для инструкций по установке, переходите к главе «[Начало работы](/ru/getting-started/)».
