# Интеграции  :id=intro

## Redmine  :id=redmine

Интеграция с системой управления проектов Redmine позволяет синхронизировать задачи и проекты, созданные в ней и в трекере.

### Глобальные настройки  :id=redmine-global

Чтобы включить или отключить возможность синхронизации с Redmine необходимо изменить параметр в разделе `Настройки организации`.

### Настройки для пользователя  :id=redmine-personal

Каждый пользователь должен задать персональный ключ, который будет использовать Cattr для синхронизации. Ключ можно получить в разделе `Моя учетная запись`.
