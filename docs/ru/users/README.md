# Пользователи

!> Для работы с пользователями компании у вашего аккаунта должны быть полномочия `root`

Пользователь может сменить свою почту, отображаемое имя, пароль и язык, на котором будет отображаться панель управления через раздел `Настройки`

Список пользователей можно посмотреть через раздел меню `Организации`

## Часовой пояс

Часовой пояс можно задавать как для компании, так и для пользователя. В часовом поясе компании генерируются и отображаются отчеты и он считается часовым поясом для пользователей, у которых он не задан принудительно.

Если часовой пояс задается для пользователя, то при учете его времени в отчетах будет внесена поправка на разницу часовых поясов пользователя и компании.
