# Права доступа  :id=intro

!> Для работы с пользователями компании и их доступом у вашего аккаунта должна быть роль `root`

Доступ пользователей к тем или иным разделам Cattr регулируется путем назначения и снятия ролей.

## Существующие роли  :id=existing

В настоящий момент существуют следующие роли:
- `root` - имеет доступ ко всем разделам
- `observer` - 
- `manager` - может просматривать, создавать и редактировать пользователей; просматривать, создавать, редактировать и удалять проекты и задачи
- `auditor` - может смотреть всех пользователей, все проекты и задачи; создавать задачи
- `user` - может создавать интервалы и скриншоты; смотреть назначенные ему задачи

Первый пользователь, созданный в системе с помощью установщика, имеет роль `root`.

## Назначение ролей  :id=promote

Роль может быть назначена пользователю как для огранизации, так и для конкретного проекта. Для изменения текущих ролей пользователя необходимо зайти в `Настройки организации` в раздел `Пользователи`.

Для назначения роли для конкретного проекта необходимо выбрать это проект в выпадающем меню (можно вводить символы для поиска) и требуемую роль.

## Ручное добавление времени  :id=manual

Для включения возможности добавлять время вручную у пользователя необходимо поставить соответствующую настройку в профиле.
