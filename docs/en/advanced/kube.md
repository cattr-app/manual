# Installation in Kubernetes :id=kube :priority=8

The server repository contains the Helm chart in .helm. This guide uses that chart directly from GitHub. You need Helm 3, a Kubernetes cluster, a StorageClass or pre-created PersistentVolumeClaims, and an Ingress controller if you want public ingress.

## Get the chart

Clone the current server repository:

~~~bash
git clone https://github.com/cattr-app/server-application.git
cd server-application
~~~

Create values.yaml. Set the image fields to GHCR explicitly: the chart defaults still point at the previous image registry. Replace the example passwords before installing and keep this file out of Git.

~~~yaml
image:
  registry: ghcr.io
  repository: cattr-app/server
  tag: latest # Prefer a released version tag for production.

cattr:
  appUrl: https://cattr.example.com
  appKey: "" # Generated by the chart when empty.

database:
  host: "" # Empty uses the MySQL instance deployed by this chart.
  name: cattr
  username: cattr
  password: REPLACE_WITH_A_LONG_RANDOM_PASSWORD
  rootPassword: REPLACE_WITH_ANOTHER_RANDOM_PASSWORD

mysql:
  enabled: true

ingress:
  enabled: true
  className: nginx
  hostname: cattr.example.com
  tls:
    - secretName: cattr-tls
      hosts:
        - cattr.example.com
~~~

Create the TLS secret cattr-tls in the cattr namespace, or adjust the values to the secret and hostname you use. To expose the service without Ingress, set ingress.enabled to false and configure an appropriate Service type or your own gateway.

## Install and update

Install or update the release:

~~~bash
helm upgrade --install cattr ./.helm \
  --namespace cattr \
  --create-namespace \
  --values values.yaml
~~~

To update the chart, pull the latest repository changes and rerun the same command:

~~~bash
git pull
helm upgrade --install cattr ./.helm \
  --namespace cattr \
  --values values.yaml
~~~

The chart deploys MySQL by default. For an external MySQL server, set mysql.enabled to false and provide database.host, database.port, database.name, database.username, database.password, and database.rootPassword as required by the chart.

The Kubernetes Service listens on port 80 and forwards to the application container on port 8080. Prometheus metrics are available at /actuator/prometheus on the service.

See the [server repository](https://github.com/cattr-app/server-application) and its [published container image](https://github.com/cattr-app/server-application/pkgs/container/server) for current release information.
