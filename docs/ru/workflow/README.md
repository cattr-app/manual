# Рабочий цикл

## Создание проекта  :id=project

!> Проекты могут создавать пользователи с полномочиями `manager`

1. Для создания нового проекта необходимо перейти в раздел `Проекты`
2. Выбрать пункт `Создать`
3. Задать параметры проекта (Название, описание)
4. Подтвердить создание кнопкой `Сохранить`

Параметр `Важно` определяет то 

Как назначать менеджеров проекта, которые смогут добавлять новые задачи можно прочитать в разделе [Система ролей](ru/roles/).

После создания проекта можно, добавлять к нему задачи и назначать их исполнителей.

## Создание задачи  :id=task

!> Задачи могут создавать пользователи с полномочиями `manager` или `auditor`

1. Для создания нового проекта необходимо перейти в раздел `Задачи`
2. Выбрать пункт `Создать`
3. Задать параметры задачи (Название, описание, приоритет)
4. Из выпадающего меню выбрать проект, в котором будет создана новая задача (По мере набора символов в поле ввода будет производиться поиск и предлагаться найденные проекты)
5. Из выпадающего меню выбрать пользователя, которому данная задача будет назначена  (По мере набора символов в поле ввода будет производиться поиск и предлагаться найденные пользователи)

Параметр `Важно` определяет то 

После добавления задачи, назначенный на нее пользователь сможет учитывать потраченное на нее рабочее время.

?> Можно автоматически создавать проекты и задачи, подключив к Cattr одну из [интеграций](ru/integrations/)

## Трекер  :id=tracker

Для авторизации в трекере необходимо использовать адрес, на котором находится ????-составляющая и связку почта-пароль от пользователя.

После авторизации будет выведен список задач, которые назначены данному пользователю, а также время, отработанное за текущий день.

При клике на название задачи можно посмотреть ее описание. Для начала учёта рабочено времени необходимо активировать отсчет, кликнув на время радом с задачей. Остановить таймер можно нажав на общий счетчик времени (внизу) или на счетчик времени рядом с конкретной задачей.
