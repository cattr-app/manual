
# Интеграция Cattr с системами контроля доступа

Эта инструкция демонстрирует использование Cattr в качестве библиотеки для интеграции с системами контроля доступа на предприятии, позволяя автоматически учитывать рабочее время сотрудников.

## Сценарий использования

Предприятие использует систему контроля доступа, регистрирующую время прихода и ухода сотрудников.  Цель - интегрировать эту систему с Cattr для автоматического учета рабочего времени, подтверждая присутствие сотрудников фотографиями с камер видеонаблюдения.

## Архитектура решения

Решение состоит из трех основных компонентов:

1. **Система контроля доступа:** Регистрирует события прохода сотрудников и предоставляет данные о времени и фотографии с камер.

2. **Интегратор (приложение-посредник):**  Выполняет взаимодействие между системой контроля доступа и Cattr API.

3. **Cattr (используется как библиотека):**  Предоставляет API для создания задач, интервалов времени и загрузки скриншотов, используемых для учета рабочего времени.

## Функции Интегратора

* **Аутентификация в Cattr:** Получает токен доступа к Cattr API.
* **Получение данных о проекте и задаче:** Определяет проект и задачу в Cattr для учета времени.
* **Получение данных о пользователях:** Сопоставляет сотрудников в системе контроля доступа с пользователями Cattr.
* **Обработка событий прохода:**  Реагирует на события прихода/ухода сотрудников.
* **Создание задачи:** Создает задачу в Cattr при приходе сотрудника.
* **Создание интервалов времени:** Создает интервалы времени (например, каждые 5-10 минут) на основе данных о присутствии.
* **Загрузка скриншотов:** Загружает фотографии с камер видеонаблюдения в Cattr, связывая их с интервалами времени.


## Настройка Cattr

1. **Создание пользователя с правами:** Создайте пользователя в Cattr с правами на создание интервалов времени для других пользователей.
2. **Создание проекта:** Создайте проект для учета рабочего времени.
3. **Создание пользователей:** Создайте пользователей в Cattr, соответствующих сотрудникам предприятия.

## Cattr как библиотека

В этом сценарии Cattr выступает в роли библиотеки, предоставляя API для внешнего взаимодействия.  Интегратор использует этот API для реализации необходимой функциональности, не вникая во внутреннюю логику Cattr.

Ключевые признаки использования Cattr как библиотеки:

* **Предоставление API:** Взаимодействие осуществляется исключительно через API.
* **Модульность и абстракция:** Функциональность учета времени используется как отдельный модуль.
* **Повторное использование:** API Cattr может быть использован в других приложениях.
* **Вспомогательная роль:** Cattr предоставляет сервисы, используемые Интегратором, а не является самостоятельным решением.
