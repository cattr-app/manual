# Введение :id=intro :priority=10

Cattr — это приложение с открытым исходным кодом, созданное для управления проектами и отслеживания рабочего времени. Благодаря интеграциям с популярными таск-трекерами (такими как Jira, Redmine, Gitlab и Trello) и встроенному функционалу отслеживания активности, это отличный инструмент для увеличения продуктивности как в офисе, так и при удалённой работе. Cattr устанавливается на ваш  сервер, что обеспечивает конфиденциальность хранения данных.

## Если вы — пользователь
Для начала работы, вам потребуются данные для доступа к учётной записи — адрес сервера, адрес электронной почты и пароль. Эти данные вы можете получить у системного администратора или руководства вашей компании. После получения учётных данных, загрузите приложение для вашей платформы на странице загрузки — [https://cattr.app/desktop](https://cattr.app/desktop)

?> Если у вас Windows, при попытке запустить приложение Вы увидите предупреждение Microsoft SmartScreen. Это происходит из-за того, что приложение пока недостаточно популярно. Для продолжения установки нажмите сначала на ссылку “Подробнее”, а затем на кнопку “Выполнить в любом случае”. Если вы чувствуете себя небезопасно, Вы можете создать приложение для компьютера из исходного кода самостоятельно: https://cattr.app/desktop-application   

При первом запуске приложение попросит вас ввести адрес сервера и данные вашей учетной записи - адрес электронной почты и пароль. После успешного входа в систему вы попадете на страницу со списком ваших задач. Для начала отслеживания рабочего времени нажмите на кнопку справа от названия задачи. В нижней части приложения вы увидите, какая задача сейчас активна, и общее количество отработанного времени за сегодня. Для остановки отслеживания времени нажмите на кнопку с таймером ещё раз.

?> Обратите внимание, что приложение для macOS запросит у вас разрешение на доступ к возможностям универсального доступа (для отслеживания активности клавиатуры и мыши) 
и записи экрана (для создания скриншотов). 

Для того, чтобы воспользоваться остальным функционалом Cattr, перейдите в веб-форму приложения: откройте браузер и введите адрес сервера, который вам предоставил администратор вашей компании. Для входа введите те же адрес электронной почты и пароль, которые вы использовали для входа в приложение на компьютере. Для настройки интеграций с системами управления проектов обратитесь за инструкциями к администратору вашей компании.

## Если вы руководите компанией
Cattr позволит вам сделать работу компании более прозрачной и эффективной. Cattr имеет несколько инструментов, каждый из которых помогает решить определенный круг задач.

### Скриншоты и отслеживание активности
Для каждого пользователя вы можете отдельно активировать запись скриншотов и отслеживание активности клавиатуры и мыши.
Эти инструменты помогут точнее подсчитывать рабочее время, идентифицируя каждую задачу, и анализировать рабочую активность сотрудников.

### Дашборд
Дашборд позволяет увидеть то, над чем работают ваши сотрудники — как в реальном времени, так и в ретроспективе.

### Отчет по проектам
Данный отчёт показывает отработанное время в отдельных проектах  за выбранный промежуток времени.

### Отчет по использованию времени
Данный отчёт показывает отработанное время конкретных сотрудников на выбранных проектах и задачах.

### Отчет по запланированному времени
Данный отчёт показывает запланированное и отработанное время конкретных сотрудников на выбранных проектах и задачах, а также продуктивность выполнения задачи.

## Установка
Обратите внимание на то, что Cattr — это on-premises приложение, которое требует установки на сервер в рамках вашей инфраструктуры.
Для инструкций по установке, переходите к главе «[Начало работы](/ru/getting-started/)»..
